## 三、方式一：Docker 一键启动（推荐）

最简单的方式，一条命令启动全部服务：

```bash
cd /Users/qinghang/Documents/QoderWorkSpace/MyApp/buyer-show

# 构建并启动全部服务
docker compose up --build -d

# 查看运行状态
docker compose ps

# 查看日志
docker compose logs -f
```

### 启动后的服务清单

| 服务 | 地址 | 说明 |
|------|------|------|
| **Web 前端** | http://localhost:3000 | Nginx 托管 React SPA |
| **API 后端** | http://localhost:8080 | Spring Boot API |
| **Swagger UI** | http://localhost:8080/swagger-ui.html | API 文档 |
| **MySQL** | localhost:3306 | root/rootpass 或 app/devpassword |
| **Redis** | localhost:6379 | 缓存 |
| **Elasticsearch** | http://localhost:9200 | 全文搜索 |
| **RabbitMQ** | http://localhost:15672 | app/devpassword（管理界面） |
| **MinIO** | http://localhost:9001 | minioadmin/minioadmin（管理界面） |

### 常用 Docker 命令

```bash
# 停止全部
docker compose down

# 停止并清除数据卷（重置数据库）
docker compose down -v

# 只启动基础设施（不启动 API 和 Web）
docker compose up -d mysql redis elasticsearch rabbitmq minio

# 重新构建某个服务
docker compose up --build -d api

# 进入 MySQL 命令行
docker compose exec mysql mysql -u app -pdevpassword buyershow

# 查看 API 日志
docker compose logs -f api
```

## 四、方式二：手动逐项启动

适合需要调试或修改代码的场景。

### 4.1 启动基础设施（Docker）

```bash
cd /Users/qinghang/Documents/QoderWorkSpace/MyApp/buyer-show

# 只启动中间件
docker compose up -d mysql redis elasticsearch rabbitmq minio

# 等待 MySQL 就绪
docker compose wait mysql
```

验证中间件状态：

```bash
# MySQL
docker compose exec mysql mysqladmin ping -u app -pdevpassword
# → mysqld is alive

# Redis
docker compose exec redis redis-cli ping
# → PONG

# Elasticsearch
curl -s http://localhost:9200 | python3 -m json.tool
# → "status": 200

# RabbitMQ
curl -s -u app:devpassword http://localhost:15672/api/overview | python3 -m json.tool

# MinIO
# 浏览器打开 http://localhost:9001
```

### 4.2 启动后端（Spring Boot）

```bash
cd /Users/qinghang/Documents/QoderWorkSpace/MyApp/buyer-show/server

# 首次构建（下载依赖，约 2-3 分钟）
mvn clean install -DskipTests

# 启动（自动执行 Flyway 数据库迁移）
mvn spring-boot:run

# 或者打包后运行
mvn clean package -DskipTests
java -jar target/buyer-show-server-1.0.0-SNAPSHOT.jar
```

验证后端：

```bash
# 健康检查
curl http://localhost:8080/api/v1/health
# → {"code":0,"message":"success","data":{"status":"UP",...}}

# 注册测试用户
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"test123","nickname":"测试用户"}'

# 登录
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"test123"}'
```

### 4.3 启动前端（Vite）

```bash
cd /Users/qinghang/Documents/QoderWorkSpace/MyApp/buyer-show/frontend

# 安装依赖（首次）
npm install

# 启动开发服务器
npm run dev
```

### 4.4 完整启动脚本

创建一个 `start-dev.sh` 一键启动开发环境：

```bash
#!/bin/bash
set -e

PROJECT_DIR="/Users/qinghang/Documents/QoderWorkSpace/MyApp/buyer-show"

echo "🚀 启动买家说开发环境..."

# 1. 启动中间件
echo "📦 启动中间件（MySQL + Redis + ES + RabbitMQ + MinIO）..."
cd "$PROJECT_DIR"
docker compose up -d mysql redis elasticsearch rabbitmq minio

# 2. 等待 MySQL 就绪
echo "⏳ 等待 MySQL 就绪..."
for i in $(seq 1 30); do
  if docker compose exec -T mysql mysqladmin ping -u app -pdevpassword --silent 2>/dev/null; then
    echo "✅ MySQL 就绪"
    break
  fi
  sleep 2
done

# 3. 启动后端
echo "🔧 启动 Spring Boot 后端..."
cd "$PROJECT_DIR/server"
mvn spring-boot:run -Dspring-boot.run.jvmArguments="-Xmx512m" &
BACKEND_PID=$!
echo "   后端 PID: $BACKEND_PID"

# 4. 等待后端就绪
echo "⏳ 等待后端就绪..."
for i in $(seq 1 60); do
  if curl -s http://localhost:8080/api/v1/health > /dev/null 2>&1; then
    echo "✅ 后端就绪"
    break
  fi
  sleep 3
done

# 5. 启动前端
echo "🎨 启动 Vite 前端..."
cd "$PROJECT_DIR/frontend"
npm run dev &
FRONTEND_PID=$!
echo "   前端 PID: $FRONTEND_PID"

echo ""
echo "✅ 全部启动完成！"
echo "   前端: http://localhost:5173"
echo "   后端: http://localhost:8080"
echo "   Swagger: http://localhost:8080/swagger-ui.html"
echo "   RabbitMQ: http://localhost:15672 (app/devpassword)"
echo "   MinIO: http://localhost:9001 (minioadmin/minioadmin)"
echo ""
echo "停止: kill $BACKEND_PID $FRONTEND_PID && cd $PROJECT_DIR && docker compose down"

# 保持前台
wait
```

## 五、数据库初始化

Flyway 会在 Spring Boot 启动时自动执行 `server/src/main/resources/db/migration/V1__init_schema.sql`，创建全部 11 张表。

### 手动执行 SQL

```bash
# 进入 MySQL
docker compose exec mysql mysql -u app -pdevpassword buyershow

# 查看表
SHOW TABLES;

# 查看用户
SELECT * FROM users;

# 查看帖子
SELECT * FROM posts ORDER BY created_at DESC LIMIT 10;
```

### 重置数据库

```bash
# 停止并删除数据卷
docker compose down -v

# 重新启动（Flyway 会重新执行迁移）
docker compose up -d mysql
```

前端开发时需要配置 API 代理，避免跨域问题。

```typescript
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: { '@': path.resolve(__dirname, './src') },
  },
  server: {
    port: 5173,
    open: true,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
      },
    },
  },
})
```

## 七、环境变量说明

### 后端（server/src/main/resources/application.yml）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `server.port` | 8080 | API 端口 |
| `spring.datasource.url` | jdbc:mysql://localhost:3306/buyershow | MySQL 连接 |
| `spring.datasource.username` | root | MySQL 用户名 |
| `spring.datasource.password` | rootpass | MySQL 密码 |
| `spring.data.redis.host` | localhost | Redis 地址 |
| `spring.rabbitmq.host` | localhost | RabbitMQ 地址 |
| `jwt.secret` | (内置) | JWT 签名密钥 |
| `jwt.access-token-expiration` | 1800000 (30min) | access token 过期时间 |
| `jwt.refresh-token-expiration` | 604800000 (7天) | refresh token 过期时间 |
| `minio.endpoint` | http://localhost:9000 | MinIO 地址 |
| `minio.bucket-name` | buyershow-images | 图片存储桶 |

### Docker Compose 环境变量

Docker Compose 中通过 `environment` 段覆盖默认配置：

```yaml
api:
  environment:
    SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/buyershow  # 容器间通信用服务名
    SPRING_DATASOURCE_USERNAME: app
    SPRING_DATASOURCE_PASSWORD: devpassword
```

## 八、常见问题

### Q: MySQL 启动失败

```bash
# 查看日志
docker compose logs mysql

# 常见原因：端口被占用
lsof -i :3306
# 解决：kill 占用进程或修改 docker-compose.yml 端口映射
```

### Q: 后端启动报 Flyway 迁移失败

```bash
# 查看迁移状态
docker compose exec mysql mysql -u app -pdevpassword buyershow -e "SELECT * FROM flyway_schema_history"

# 重置迁移（危险：会删除所有数据）
docker compose exec mysql mysql -u app -pdevpassword buyershow -e "DROP DATABASE buyershow; CREATE DATABASE buyershow CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### Q: 前端 npm install 很慢

```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
cd frontend
rm -rf node_modules package-lock.json
npm install
```

### Q: Java 版本不对

```bash
# 检查当前 Java 版本
java -version

# 切换到 Java 21
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH=$JAVA_HOME/bin:$PATH
```

### Q: Docker 内存不足

Docker Desktop → Settings → Resources → Memory 至少分配 4GB（推荐 8GB，因为 ES 需要 512MB+）。

### 9.2 CI/CD 流水线

```yaml
# .github/workflows/deploy.yml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  build-push:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with:
          registry: registry.cn-hangzhou.aliyuncs.com
          username: ${{ secrets.REGISTRY_USER }}
          password: ${{ secrets.REGISTRY_PASSWORD }}
      - name: Build & Push API
        run: |
          docker build -t registry.cn-hangzhou.aliyuncs.com/buyershow/api:${{ github.sha }} server/
          docker push registry.cn-hangzhou.aliyuncs.com/buyershow/api:${{ github.sha }}
      - name: Build & Push Web
        run: |
          docker build -t registry.cn-hangzhou.aliyuncs.com/buyershow/web:${{ github.sha }} frontend/
          docker push registry.cn-hangzhou.aliyuncs.com/buyershow/web:${{ github.sha }}
```
